# Security Policy

## Reporting a vulnerability

Email support@getgovinbox.com with the subject "Security". Include a description of the issue, steps to reproduce, and the impact.

We aim to acknowledge reports within 48 hours. Please do not disclose the issue publicly until we have had a chance to fix it.

## Scope

This policy covers the GovInbox MCP integration in this repo and the hosted MCP endpoint at mcp.getgovinbox.com.
